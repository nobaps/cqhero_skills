# cqhero_skills

个人 Skill（技能）合集仓库。每个技能一个独立目录，目录内自成体系（含 `SKILL.md`、脚本、参考资料与测试）。

## 技能清单

| 目录 | 技能 | 一句话说明 | 版本 | 状态 |
|---|---|---|:--:|---|
| [`lunar_kline/`](./lunar_kline/) | 干支月K线图<br>`lunar-kline-chart` | 以**十二节气**定月界（立春起为寅月）、**立春**定年界，按天干地支重排行情并绘制 K 线；支持年K/月K/日K三级切换与点击下钻，附成交量与 MACD 窗格，输出自包含交互式 HTML | v0.6.0 | ✅ |

## 目录约定

```
<技能目录>/
├── SKILL.md            # 技能定义（frontmatter + 使用说明），入口文件
├── scripts/            # 可执行脚本
├── references/         # 权威口径 / 规格文档
├── templates/          # 模板资源
├── test/               # 测试与验证脚本
└── examples/           # 示例产出（可选）
```

`runs/` 为运行时产物目录，已加入 `.gitignore`，不入库。

## 使用方式

将需要的技能目录放入 WorkBuddy 的技能目录即可被识别：

- 用户级：`~/.workbuddy/skills/`
- 项目级：`<项目>/.workbuddy/skills/`

各技能的具体依赖与用法见其目录内的 `SKILL.md`。

## 说明

- 本仓库技能多为**工具型**：提供某种视角或便利，不承诺"效果优于裸模型"。
- 涉及金融数据的技能**仅做中性数据呈现**，不提供买卖信号或涨跌预测。
