# 干支月K线图 · lunar-kline-chart

> **完整技能定义与口径说明见 [`SKILL.md`](./SKILL.md)**（本文件仅为快速上手）。

按**天干地支**维度重排行情并绘制 K 线图。

- **月分界**：十二节气（立春起为**寅月**，惊蛰起为卯月……），一年恒 12 个干支月 —— 因此**不存在闰月问题**。
- **年分界**：立春。
- **横轴一律干支**：年K = 干支年（丙午年）、月K = 干支月（庚寅月）、日K = 干支日（甲子日）。
- **数据源**：腾讯行情（免密钥、前复权）。
- **定位**：中性数据呈现，只呈现历史，**不提供买卖信号或涨跌预测**。

## 快速开始

无需安装任何第三方依赖（纯 Python 标准库，Python 3.8+）。

```bash
# 一键出交互图：取数 → 日/干支月/干支年三层聚合 → 渲染自包含 HTML
python scripts/build_chart.py sh000001 2020-01-01 2026-04-15

# 查某日所属干支月
python scripts/ganzhi.py term 2026-02-04
# → {"gz_month":"庚寅","gz_year":"丙午","jie":"立春", ...}

# 列出某年 12 个干支月
python scripts/ganzhi.py months 2026
```

默认输出到 `runs/<时间戳>/<代码>.html`，单文件自包含、可离线打开。

## 界面交互

| 交互 | 说明 |
|---|---|
| 级别切换 | 年K（干支年）/ 月K（干支月）/ 日K（干支日） |
| 点击下钻 | 点月K某月 / 年K某年 → 展示其内部全部日K，面包屑返回 |
| 滚轮缩放 | 以光标处为锚点放大缩小 |
| Shift + 拖拽 | 平移可见窗口 |
| 左键拖拽框选 | 框选区间并统计（精确到柱） |
| 双击 | 复位全量视图并清除框选 |
| 悬停 | 竖排 OHLCV + 日期与干支提示 |
| 副图窗格 | 成交量（手）、MACD(12,26,9) |

## 关键实现说明

- 节气与干支由 `scripts/ganzhi.py` 用**太阳视黄经天文算法确定性计算**，不依赖模型推理。
  实测精度约 1 分钟（2026 冬至算出 12-22 04:49，官方值 04:49:55）；对外口径为**日级**，交节当日整日归入新月。
- 下钻分组以 **「干支年 + 干支月」复合唯一键** 为索引 —— 干支月名会跨年重复
  （如丙子月每年都有），仅用月名做键会把其它年份的同名月份数据错误带入。
- 单次取数存在 **2000 行上限**（超限静默截断），故按 5 年分段请求后合并去重。
