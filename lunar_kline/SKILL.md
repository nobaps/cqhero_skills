# 干支月K线图

**定位：工具型技能。** 提供一种**看盘视角**（干支月维度）+ **使用便利**（一键出图，免去自行实现节气算法）。
不承诺"效果优于裸模型"——正如均线、MACD、筹码分布，指标的价值在于**多一个看市场的角度**，不在"比人聪明"。

> 关于换算精度的 A/B 对照见 `test/ab_report.md`：**换算准确度上相对裸模型无明显增益**。
> 该实验**仅用于量化精度对比，不用于判定本技能价值**（视角价值与便利价值无法用 A/B 测量）。

按**天干地支月（节气月）**重排行情并绘制 K 线图。

**核心定义**：月分界用**十二节气**——立春起为寅月，惊蛰起为卯月，依次类推，一年恒 12 个干支月。**不是**农历朔望月，因此**不存在闰月问题**。

> **本技能的关键增益**：节气日期与干支换算由 `scripts/ganzhi.py` 用**天文算法确定性计算**，不依赖模型推理。模型凭记忆算节气/干支会出错——实测中经验系数表把 2026 立春算成 2 月 1 日（正确为 2 月 4 日），天文算法则准确命中。

## 什么时候用

用户要「按农历/节气画 K 线」「干支月 K 线」「庚寅月/辛卯月涨幅」「按节气月看走势」。

## 不适用（必须拒绝或转向）

| 请求 | 处理 |
|---|---|
| 纯公历日期绘图 | 不在本技能范围 |
| 只查实时/历史行情 | 属取数，非本技能职责 |
| 「什么时候买/卖」「下周涨还是跌」 | **拒绝**。改为呈现历史干支月统计，由用户自行判断 |
| 预测未来点位 | **拒绝** |

## 口径（已定稿，见 `@references/calendar-spec.md`）

| 项 | 取值 |
|---|---|
| 月分界 | 十二节气（立春=寅月，惊蛰=卯月…） |
| 坐标标签 | 天干地支月名（庚寅月、辛卯月） |
| 闰月 | 不存在此问题 |
| 非交易日 | 跳过 |
| 数据源 | 腾讯行情（免密钥，前复权） |
| 定位 | 中性数据呈现，只提示不建议 |

## 输入

| 参数 | 说明 | 必填 |
|---|---|---|
| 标的 | 代码，支持 `sh000001` / `000001` / `600519` | 是 |
| 起止日期 | 公历 `YYYY-MM-DD` | 是 |
| 输出路径 | 默认为 `runs/<时间戳>/<代码>.html` | 否 |

## 步骤

```bash
# 一键出交互图（取数 → 日/干支月/干支年三层聚合 → 渲染）
python scripts/build_chart.py sh000001 2020-01-01 2026-04-15

# 查某日所属干支月
python scripts/ganzhi.py term 2026-02-04
# → {"gz_month":"庚寅","gz_year":"丙午","jie":"立春",...}

# 列出某年 12 个干支月
python scripts/ganzhi.py months 2026
```

## 输出格式

单文件 HTML（内联 SVG），自包含、可离线打开。**图内强制携带**：本次口径说明、数据区间、免责声明。缺 `calendar_spec` 时渲染脚本 `EXIT 1`，不产出裸图。

颜色惯例：**红涨绿跌**（中国市场惯例）。

## 红线

- **不做投资建议**：不输出买卖时点、目标价、涨跌预测。所有输出必须带"历史数据整理，不构成投资建议"。
- **不编造数据**：取数失败就报错说明原因，不得用占位数据补全图表。
- **不裸露 traceback**：异常收敛为错误码（`NO_DATA` / `NETWORK_FAIL` / `BAD_RESPONSE` / `BAD_INPUT` / `OUT_OF_RANGE` / `MISSING_SPEC`）。

## 边界与异常

| 情形 | 处理 |
|---|---|
| 非交易日 | 跳过 |
| 停牌 | 该日无数据，自然跳过 |
| 区间内无交易日 | 报 `NO_DATA`，不产出空图 |
| 网络不可达 | 报 `NETWORK_FAIL`，提示检查网络；**不回退到编造数据** |
| 节气精度 | 算法精度约 **1 分钟**；对外**口径为日级**，交节当日整日归入新月 |

## 已实测的坑（写进降级设计）

1. **复权数据键名不同**：请求带 `qfq` 时个股数据在 `qfqday` 键下，指数在 `day` 键下。不兼容会静默返回空（实测 600519 直接 KeyError）。脚本按 `qfqday`→`day` 顺序探测。
2. **字段顺序**：返回为 `[日期, 开, 收, 高, 低, 量]`，**第 2、3 位是开、收**，不是开、高。写错会导致 K 线全错。已用 37/37 行行情约束验证。
3. **东财接口本环境不可达**（`RemoteDisconnected`）；新浪仅提供实时快照无历史 K 线。故采用腾讯单源，并在取数失败时明确报错而非静默降级。

## 降级设计

| 依赖 | 缺失时 |
|---|---|
| 网络 / 行情接口 | 报 `NETWORK_FAIL`，提示用户检查网络后重试；**不得返回空图或占位数据** |
| Python 环境 | 需 Python 3.8+；**纯标准库，零第三方依赖** |
| 节气精度 | 算法约 1 分钟精度；技能对外口径为日级 |

## 交互设计

输出为**自包含单文件 HTML**（数据全内联，离线可用），含多层交互：

| 交互 | 说明 |
|---|---|
| **级别切换** | 顶部按钮切换 年K（干支年）/ 月K（干支月）/ 日K（交易日）——同一批数据换粒度看 |
| **点击下钻** | 月K 点某月 → 展示该干支月内全部日K；年K 点某年 → 展示该干支年内全部日K |
| **返回** | 下钻后点面包屑「← 返回」回到上级视图 |
| **鼠标框选区间统计** | **左键拖拽**框选一段 → 高亮选区 + 统计该段（精确到柱）；单击空白或「清除框选」取消 |
| **滚轮缩放** | 以**光标处为锚点**放大/缩小，柱体过密时用它细看 |
| **Shift+拖拽平移** | 放大后按住 Shift 拖动平移窗口（普通拖拽已让位给框选） |
| **双击复位** | 双击图表恢复全量视图并清除框选 |
| **悬停竖排提示** | 鼠标停留显示该柱 **竖排** OHLCV（开/高/低/收/量各占一行）+ 日期与干支 |
| **成交量窗格** | 主图下方绘制成交量柱（红涨绿跌、单位「手」），与 K 线共享横轴 |
| **MACD 窗格** | 再下方绘制 DIF / DEA / 柱（参数 12,26,9），共享横轴 |
| **区间统计** | 面板对**框选区间**（无框选时退化为可见区间）按**日线**口径汇总 |

**关键实现约定**：
- 下钻为**纯前端切换**（数据已内联），不需联网、不起服务。
- 下钻分组必须以 **「干支年 + 干支月」唯一键**为索引——**干支月名会跨年重复**（如丙子月每年都有，
  实测 6 年区间出现 17 组重名），仅用月名做键会把其它年份的同名月份数据错误带入。
- 级联筛选：缩放/平移只改可见窗口，**不改变聚合口径**——柱体仍是干支年/月/日。
- **横轴一律干支**：年K=干支年（如丙午年）、月K=干支月（如庚寅月）、日K=**干支日**（如甲子日）。
  日柱由 `ganzhi.py` 的 `day_gz()` 按 `(JDN+49) mod 60` 计算，锚点校对
  （2024-01-01=甲子日、2000-01-01=戊午日，公开万年历）。
- 区间统计**口径声明**：对当前可见区间、基于**日线**汇总（涨跌=末收/首开−1），
  避免月/年聚合柱造成的口径漂移。

## 已知限制（诚实声明）
- 节气由天文算法（太阳视黄经）计算，实测精度约 **1 分钟**（2026 冬至算出 12-22 04:49，官方值 04:49:55）。对外口径为**日级**：交节当日整日归入新月。
- 数据源为**单一来源**（腾讯，前复权），无多源交叉校验；接口若变更需同步更新。
  该源**只提供成交量、不提供成交额**：实测东财（短区间偶尔可用、长区间稳定 `RemoteDisconnected`）与
  网易（`chddata` 502）在本环境均不可用，故成交量窗格**只能呈现「量」口径**，不能呈现「成交额」。
- ⚠️ **关于"效果增益"**：A/B 对照（见 `test/ab_report.md`）显示，在**换算准确度**维度上本技能相对裸模型
  无明显增益（三轮 10-12% / 10-12% / 0%）。**但这不否定本技能的价值**——
  本技能属**工具型**，价值在"提供视角 + 降低使用门槛"，不在"效果优于裸模型"。

**v0.6.0 补充约定**：
- **成交量口径**：窗格绘制的是行情接口的**成交量**字段（单位「手」，已与东财同源数据交叉核对一致），
  **不是成交额**。实测本环境可用源中，腾讯仅给成交量，东财间歇不可达（长区间 `RemoteDisconnected`）、
  网易 `chddata` 返回 502，故**无法提供真实成交额**。若后续接入可用源，只需在 bar 上补 `amount`
  字段并改窗格取值即可（渲染层已按窗格隔离）。
- **MACD 计算域**：对**当前所绘序列**（年K/月K/日K 或下钻日K）的收盘价计算，参数 12,26,9，
  标准 EMA 递推（`EMA_0=c_0`）。样本 < 35 根时窗格标题标注「样本偏少，仅供参考」。
  MACD 缩放在**可见窗口**内自适应。
- **选区与缩放独立**：框选按**基准序号**记录（`{i0,i1}`），缩放/平移不改变选区所对应的柱，
  只影响其是否在可视范围内。
